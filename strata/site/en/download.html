Download Strata

Strata is installed with its launcher, a small Windows program that takes care of everything. It needs no administrator rights.

Download the launcher (.exe)

Windows 10 or 11, with the Discord desktop app installed.
All versions and their SHA-256 checksums: releases page.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. The launcher is built by GitHub Actions from its source code. Details: code signing policy.

Install

  1. Download strata-launcher.exe and run it. It does not need to be installed.
  2. If Windows shows "Windows protected your PC", click "More info", then "Run anyway". This message appears as long as the launcher is not signed: Windows is wary of recent programs it does not know yet.
  3. On your Discord's card, click "Installer Strata" (Install Strata). Discord closes and restarts: an ongoing call will be cut.
  4. Done. The Strata button at the top right of Discord opens the settings: accent colour, background, spacing, drawer, theme parts.

Antivirus software. An antivirus may be wary of the launcher: it is recent, and it modifies Discord's files, like Vencord's installer. If yours blocks it, check that the file comes from the releases page (and its SHA-256 checksum), then report it to your antivirus as a false positive.

Updates

Strata updates itself from its releases on GitHub. To check manually: Discord settings → Vencord → Updater. When Discord updates itself, Strata re-applies itself automatically.

Repair or uninstall

Open the launcher again:

  • Repair ("Réparer") downloads Strata again and reinstalls it, if something stopped working.
  • Uninstall ("Désinstaller") restores Discord's original file and deletes Strata's files (%APPDATA%\Strata). Your Vencord settings (%APPDATA%\Vencord\settings) are kept, in case you reinstall Strata or Vencord.

Frequently asked questions

I already use Vencord.
The launcher says so ("Vencord ou autre mod") and offers to replace it with Strata. Your Vencord plugins and settings are kept as they are.
What exactly does the launcher change?
In Discord's folder, it renames resources\app.asar to _app.asar and puts a tiny archive that loads Strata in its place, exactly like Vencord's official installer. Strata's files go to %APPDATA%\Strata\dist. Nothing else is touched.
What about macOS or Linux?
Not yet: the launcher is Windows-only.
Is it risky for my Discord account?
Like every modified client, Strata goes against Discord's Terms of Service. No ban for a simple theme is known, but if your account matters a lot to you, it is safer not to use a modified client.
