A cleaner, calmer Discord.

Strata is a distribution of Vencord for Discord: a dark theme in your colour, ready-made themes, gradient, translucent or picture backgrounds, floating panels, a channel drawer and a built-in settings window. Free, open source, and updated automatically.

Download for Windows Source code

Windows 10 and 11, Discord desktop app. Free, no account, no administrator rights.

What Strata changes

Everything is set in a dedicated window, opened from a button in Discord's title bar. On first launch, it offers you a theme to start with.

◈

One-click themes

A gallery of ready-made themes, and your own saved themes to switch between them in one click.

●

Colours

Eight accent colours or your own, a gradient accent, and the colours of the status dots.

◐

Backgrounds

Solid, gradient, translucent like Nitro themes, or a picture from your computer, with adjustable blur and brightness.

▦

Floating panels

Channels, messages and members as rounded cards: adjustable spacing, corners, borders, shadows and accent glow.

⇥

Channel drawer

Folded away, the channel list leaves room for the chat; it opens when you hover the server bar.

Aa

Text and shapes

Any font installed on your computer, message size, spacing, size and shape of avatars and server icons.

◌

Clean mode

Hide what you don't use, one by one: Nitro, Shop, Quests, gift, GIF and sticker buttons…

↻

Automatic updates

Strata updates itself, shows what's new, and re-applies itself when Discord updates.

◇

Vencord included

All of Vencord's plugins remain available, and your existing Vencord settings are kept.

The settings window

Everything is set in one place and applies live, without restarting Discord. The window is in French for now.

One-click install

The launcher finds the Discord clients installed on the PC and shows whether each one is original, already running Strata, or modified by something else. It speaks English and French: you pick the language on first launch.

  • Install, repair or uninstall: one button per action.
  • No administrator rights, nothing left running in the background.
  • Uninstalling restores Discord to its original state.

Open source and transparent

  • Public source code under the GPL-3.0 licence: Strata and its launcher.
  • Every distributed file is built by GitHub Actions from that code.
  • No data collection, no telemetry: see the privacy policy.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Details are in our code signing policy. Signing is not active yet.

Like every modified client (Vencord, BetterDiscord…), Strata goes against Discord's Terms of Service. No ban for a simple theme is known, but everyone installs it knowingly. Strata is not affiliated with Discord Inc. or with the authors of Vencord.
