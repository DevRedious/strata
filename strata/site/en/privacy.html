Privacy policy

Last updated: 22 October 2026. It covers Strata and the Strata launcher.

In short: neither Strata nor its launcher collects personal data. No account, no telemetry, no usage statistics. The only connections are those described below, and none of them carries personal data.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The launcher

  • On start-up, it asks api.github.com for the name of the latest Strata release, to display it.
  • When you install or repair Strata, it downloads its files from github.com.

These requests only carry the header User-Agent: StrataLauncher/<version>. As with any connection to a website, GitHub sees your IP address; its privacy statement applies.

The launcher only writes to Discord's folder and to %APPDATA%\Strata. It does not read your messages, your Discord account or your files.

Strata, inside Discord

  • Settings. They stay on your computer, in %APPDATA%\Vencord\settings.
  • Updates. Strata regularly checks api.github.com for a new version and downloads it from github.com. This can be turned off in Settings → Vencord → Updater.
  • Badges. Vencord, which Strata is built on, downloads the public list of its contributors' badges from badges.vencord.dev.
  • Discord's telemetry. Vencord blocks by default the telemetry and crash reports that Discord normally sends (NoTrack plugin).

What is up to you

  • Settings sync. Vencord can sync your settings to its server (api.vencord.dev). It is off by default and only works if you set it up yourself.
  • Vencord plugins. Some optional plugins contact third-party services (a translation plugin contacts a translation service, for example). They are off by default; each describes what it does.
  • Discord. Discord is still Discord: your use of it is governed by its own privacy policy.

Contact

Strata is maintained by DevRedious. The source code of Strata and of the launcher is public: every statement above can be checked there.
