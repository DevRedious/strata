Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

La signature n'est pas encore active : la demande à SignPath Foundation est en préparation. En attendant, les exe publiés ne sont pas signés.

Ce qui est signé

Uniquement strata-launcher.exe, le launcher de Strata pour Windows. Il est compilé par GitHub Actions, sur des machines hébergées par GitHub, à partir du code de son dépôt (workflow de compilation), pour chaque version publiée. Aucun binaire compilé sur un poste de développement n'est signé ni distribué.

Le launcher télécharge ensuite les fichiers de Strata (JavaScript et CSS chargés par Discord) depuis les releases de Strata, elles aussi compilées par GitHub Actions. Ce ne sont pas des exécutables Windows : ils ne sont pas couverts par cette signature.

DevRedious

Toute contribution extérieure est relue avant d'être fusionnée. Chaque demande de signature est approuvée à la main. L'authentification à deux facteurs est exigée sur GitHub et sur SignPath.

Ce que fait le programme

Le launcher installe, répare ou désinstalle Strata sur les clients Discord de l'ordinateur, à la demande de l'utilisateur, avec un bouton par opération :

  • il ferme le client Discord concerné, après avoir prévenu qu'un appel en cours sera coupé ;
  • il renomme resources\app.asar en _app.asar dans le dossier de Discord, et écrit à sa place une petite archive qui charge Strata, comme l'installeur officiel de Vencord ;
  • « Désinstaller » rend à Discord son fichier d'origine et supprime les fichiers de Strata ;
  • il ne demande aucun droit administrateur, ne modifie rien en dehors du dossier de Discord et de %APPDATA%\Strata, et ne laisse aucun programme en arrière-plan.

Confidentialité

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Le détail des connexions est dans la politique de confidentialité.
