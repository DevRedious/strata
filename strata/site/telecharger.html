Télécharger Strata

Strata s'installe avec son launcher, un petit programme pour Windows qui s'occupe de tout. Il ne demande aucun droit administrateur.

Télécharger le launcher (.exe)

Windows 10 ou 11, avec Discord pour ordinateur installé.
Toutes les versions et leurs empreintes SHA-256 : page des releases.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Le launcher est compilé par GitHub Actions à partir de son code source. Détails : politique de signature du code.

Installer

  1. Téléchargez strata-launcher.exe et lancez-le. Il n'a pas besoin d'être installé.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur « Informations complémentaires », puis « Exécuter quand même ». Ce message apparaît tant que le launcher n'est pas signé : Windows se méfie des programmes récents qu'il ne connaît pas encore.
  3. Sur la carte de votre Discord, cliquez sur « Installer Strata ». Discord se ferme puis se relance : un appel en cours sera coupé.
  4. C'est installé. Le bouton Strata en haut à droite de Discord ouvre les réglages : couleur d'accent, fond, espacement, tiroir, parties du thème.

Antivirus. Un antivirus peut se méfier du launcher : il est récent, et il modifie les fichiers de Discord, comme l'installeur de Vencord. Si le vôtre le bloque, vérifiez que le fichier vient bien de la page des releases (et son empreinte SHA-256), puis signalez-le à votre antivirus comme faux positif.

Mises à jour

Strata se met à jour tout seul, depuis ses releases sur GitHub. Pour vérifier à la main : Paramètres de Discord → Vencord → Mettre à jour. Quand Discord se met lui-même à jour, Strata se réapplique automatiquement.

Réparer ou désinstaller

Rouvrez le launcher :

  • Réparer retélécharge Strata et le réinstalle, si quelque chose ne fonctionne plus.
  • Désinstaller rend à Discord son fichier d'origine et supprime les fichiers de Strata (%APPDATA%\Strata). Vos réglages Vencord (%APPDATA%\Vencord\settings) restent, au cas où vous réinstalleriez Strata ou Vencord.

Questions fréquentes

J'utilise déjà Vencord.
Le launcher l'indique (« Vencord ou autre mod ») et propose « Remplacer par Strata ». Vos plugins et réglages Vencord sont repris tels quels.
Que modifie le launcher exactement ?
Dans le dossier de Discord, il renomme resources\app.asar en _app.asar et met à sa place une petite archive qui charge Strata, exactement comme l'installeur officiel de Vencord. Les fichiers de Strata vont dans %APPDATA%\Strata\dist. Rien d'autre n'est touché.
Et sur Mac ou Linux ?
Pas encore : le launcher est pour Windows uniquement.
Est-ce risqué pour mon compte Discord ?
Comme tout client modifié, Strata est contraire aux conditions d'utilisation de Discord. Aucun bannissement pour un simple thème n'est connu, mais si votre compte est très important pour vous, mieux vaut ne pas utiliser de client modifié.
